# Petri Net Editor

Petri Net Editor - это приложение для создания, редактирования и анализа сетей Петри. Приложение разработано на Python с использованием библиотеки Tkinter для графического интерфейса.

## Возможности

- **Создание и редактирование сетей Петри**: Добавление позиций, переходов и дуг с помощью интуитивного графического интерфейса.
- **Симуляция**: Запуск симуляции сети Петри с поддержкой задержанных переходов и выбора переходов для срабатывания.
- **Анализ**: Выполнение анализа достижимости и ограниченности с визуализацией графа состояний.
- **Группы элементов**: Организация элементов сети в группы для удобного управления.
- **Сохранение и загрузка**: Сохранение сетей в JSON формате и загрузка из файлов.

## Требования

- Python 3.7 или выше (рекомендуется Python 3.13)

## Установка

1. Клонируйте репозиторий или скачайте исходный код.
2. Убедитесь, что Python установлен на вашем компьютере.

## Запуск

1. Откройте командную строку или терминал.
2. Перейдите в директорию проекта: `cd path/to/petry`
3. Запустите приложение: `python src/main.py`

## Структура проекта

- `src/main.py` - Точка входа в приложение.
- `src/app/PetriNetEditor.py` - Основной класс редактора.
- `src/app/modules/` - Модули для логики сети Петри, симуляции, анализа и т.д.
- `src/app/ui/` - Компоненты пользовательского интерфейса.

## Использование

1. После запуска откроется главное окно с вкладками.
2. Используйте вкладку "Инструменты" для добавления элементов на холст.
3. Вкладка "Симуляция" позволяет запускать и управлять симуляцией.
4. Вкладка "Анализ" предоставляет инструменты для анализа сети.
5. Вкладка "Группы" позволяет создавать и управлять группами элементов.
